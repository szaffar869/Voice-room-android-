VOICE ROOM — Android project

اہم: یہ Android project ہے، تیار شدہ APK نہیں۔ اس میں پچھلا HTML ڈیمو Android WebView میں چلتا ہے۔

APK بنانے کا آسان طریقہ:
1) اس ZIP کو GitHub پر ایک نئے repository میں upload کریں۔
2) GitHub repository میں Actions کھولیں۔
3) 'Build Voice Room APK' workflow منتخب کریں اور Run workflow دبائیں۔
4) Build مکمل ہونے کے بعد workflow کے نیچے Artifacts میں 'VoiceRoom-debug-apk' ڈاؤن لوڈ کریں۔
5) ZIP کھولیں؛ app-debug.apk فائل Android فون پر انسٹال کریں۔

نوٹ: موجودہ مائیک بٹن صرف ڈیمو UI ہے۔ حقیقی لوگوں کے درمیان live voice chat، اکاؤنٹس، gifting یا coins اس ورژن میں فعال نہیں ہیں۔
